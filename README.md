# shelf-pilot

Throwaway retraction pilot

This repository publishes releases only. Development happens privately.

- **Download:** [Releases](https://github.com/LumeraProtocol/shelf-pilot/releases).
- **Verify:** run `sha256sum -c SHA256SUMS` in the folder with the downloaded files.
- **Source:** each release's `shelf-pilot-<version>-src.tar.gz` asset. GitHub's "Source code" archives on a release contain only this README.
- **Go:** `go get go.lumera.io/shelf-pilot`. The old path `github.com/LumeraProtocol/shelf-pilot` no longer receives versions.

Issues are welcome; pull requests are not accepted.
